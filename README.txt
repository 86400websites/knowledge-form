Alliance Knowledge Repository

The GitHub Pages form uses Google Drive for files and Google Sheets for the searchable index. Users can create folders inside folders, upload a laptop file, save its details and retrieve it by keywords or text. Admins manage the shared keyword list on the website.

Run node test.js for the local regression suite. SETUP.txt covers deployment in the current Google account. GO_LIVE_CHECKLIST.txt covers the live-account checks. OPERATOR_GUIDE.txt covers daily use. DRIVE_HANDOVER.md contains the checklist and new-session prompt for moving uploads to Alliance's Drive while keeping the index and public form link.
