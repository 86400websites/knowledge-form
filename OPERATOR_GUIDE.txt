Click Use this folder. Check the suggested title, describe the file, and select its document type and topic. More details contains optional tags and keywords. Click Save file once. Keep the tab open until File saved appears. If your connection drops, Retry resumes the transfer. If the file is already in Drive, Retry finishes saving its details. Open file opens the saved item.

2. FIND A FILE
Open Find a file to see recent files. Use normal search or tap Filters to narrow the list. Open file is on each result. More contains the folder and related files.

3. MANAGE KEYWORDS
Use the same uploader key. Open Admin and choose Manage keywords. Select a group to add a word or choose an existing word to rename or remove. Before removing a word, check how many files use it and choose a replacement if needed.
